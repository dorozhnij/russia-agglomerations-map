# Карта городских агломераций России

Интерактивная карта муниципалитетов российских городских агломераций.

На карте:

- полигоны муниципалитетов, сгруппированные по агломерациям;
- подложка CARTO Positron;
- легенда цветов агломераций;
- название агломерации, муниципалитета, региона и код ОКТМО во всплывающем окне.

Данные муниципальных границ: версионный справочник муниципальных образований
СберИндекса, с учётом состояния на 2024 год и отдельно отмеченных исторических
территорий.
